# dualboot-r36s-clone
Dual boots latest linux 7.3.4 for testing and development purposes alongside arkos4clone

HAZARD/CAUTION/WARNING: THIS IS STILL IN STAGING AND MEANT TO BE AN IDEA!!
THIS IS ONLY VERIFIED ON R36S CLONE TYPE2 PANEL1 WO AMP.

Copy all the files in the boot folder to the BOOT partition of the (d)ArkOS4Clone.
It should present a dual boot menu just like desktop bootloaders.
Touch any key within 4 seconds to stop DEFAULT Boot to 7.3.4 kernel

Press ARROW UP/DOWN to Navigate

Press A to SELECT.
